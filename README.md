EPAM Healthcare AI Project – Sprint 2 Team 2

Project Overview

This repository contains the Python implementation developed by Team 2 for Sprint 2 of the EPAM Healthcare AI Project.

The project focuses on healthcare package matching by processing patient-related clinical information and mapping it to relevant healthcare packages.

Sprint 2 – Team 2

Key Objectives

Process structured patient information.

Perform diagnosis-to-package matching.

Identify relevant healthcare packages based on available patient information.

Generate structured JSON output for package matching results.

Technologies Used

Python

JSON

Rule-based matching and data processing
